## Week of August 8, 2026

### Updates

- **Broader automated QA coverage for the Pulse social scheduler.** New end-to-end test suites now exercise signup, login, dashboard navigation, post composition, AI caption generation, draft saving, scheduling, calendar navigation, post filtering, post deletion, and account connect and disconnect flows. These checks run on every change, so daily-use features catch regressions before you see them.
- **Upgraded deploy pipeline authentication.** The GitHub Actions Google Cloud authentication step now runs on the latest major version. Deployments continue to work as before, with an up-to-date, supported runtime under the hood.

<Note>
  No action is required. See the [Quickstart](/quickstart) to get started.
</Note>

## Week of August 1, 2026

### Updates

- **More reliable releases.** A new end-to-end testing setup now seeds and tears down realistic data across the app before every release. You get faster iteration on the features you rely on — signups, subscriptions, blog, newsletter, contact forms, and checkout — with fewer regressions.
- **Stronger security posture.** Automated code security scanning now runs on every change and on a regular schedule, so vulnerabilities are caught earlier. No action is required from you — the checks run behind the scenes to help keep your account and data safer.

<Note>
  Nothing about your account, data, or day-to-day workflow changes with this
  update. See the [Quickstart](/quickstart) to get started.
</Note>
