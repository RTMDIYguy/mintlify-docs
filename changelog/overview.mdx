## Week of September 7, 2026

### New features

- **Cross-department operating playbooks.** A new Playbooks page shows five governed journeys that connect department workflows end to end. The journeys cover lead to sale, sale to delivery, delivery to retention, finance controls, and the proof and referral loop. Each playbook spells out its trigger, completion definition, owners, approvals, handoffs between workflows, fallback and stop protocols, and evidence requirements. You can now see exactly how work moves across department boundaries and who is accountable at each step. Existing workflow IDs are unchanged. See [workflow packages](/workflows/overview) for how individual workflows are organized.

### Updates

- **Secrets vault bridged to the live environment.** Saving an API key in the Settings secrets vault now applies it to the running platform immediately, with no restart needed. Provider names are normalized to canonical keys, and credentials already configured in the environment for core providers (Instantly, HubSpot, ElevenLabs, AgentMail, Google Gemini) appear in the vault automatically with a masked preview. Connection tests now name the missing key when a credential is not configured. See [Ops Agent settings and MCP integrations](/platform/settings).
- **Real integration connection tests.** The **Test** action on Settings integrations now runs live handshakes instead of simulated pings. Instantly, ElevenLabs, and HubSpot integrations are verified against their live APIs with your configured credentials, integrations with an HTTP endpoint get a real ping with measured latency, and failures report the underlying error. See [Ops Agent settings and MCP integrations](/platform/settings).
- **TypeScript compiler upgrade.** The compiler that checks and builds the platform's code moved up two major versions to TypeScript 7, the new natively compiled release. You get faster builds and earlier detection of code issues before each release. Nothing about how the app looks or works day-to-day changes. See the [Quickstart](/quickstart) to get started.
- **Platform-wide library refresh.** More than 50 production libraries moved to their latest minor and patch releases. The refresh covers the interface components behind forms, dialogs, menus, tabs, and charts, plus AI, payments, file storage, and database connectivity. You get faster interactions, security fixes, and compatibility with the newest AI models and payment provider features. Nothing about how the app looks or works day-to-day changes. See the [Quickstart](/quickstart) to get started.
- **Package manager upgrade.** The tool that installs the platform's dependencies moved up two major versions. You get faster dependency resolution and more reliable builds behind the scenes. Nothing about how the app looks or works day-to-day changes. See the [Quickstart](/quickstart) to get started.
- **Node.js type definitions upgrade.** The Node.js type definitions used during development moved up two major versions. This keeps builds aligned with the newest Node.js APIs and catches more issues before release. Nothing about how the app looks or works day-to-day changes. See the [Quickstart](/quickstart) to get started.
- **Build tooling refresh.** The internal styling, bundling, and code formatting toolchain moved to its latest releases. You get more reliable production builds, security fixes, and small performance improvements behind the scenes. Nothing about how the app looks or works day-to-day changes. See the [Quickstart](/quickstart) to get started.
