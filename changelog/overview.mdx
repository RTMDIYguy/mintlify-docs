## Week of August 22, 2026

### Updates

- **Payments library upgrade.** The library that powers checkout and subscription billing moved to its latest major release. You get continued compatibility with the payment provider's newest APIs and security patches. Checkout and billing work the same as before.
- **UI library upgrades.** The icon library and the internal ID generator moved to their latest major releases. You get an up-to-date icon set and smaller page downloads, with no change to how the app looks or works day-to-day.
- **More reliable deployments.** The automation that authenticates to the cloud, provisions deploy tooling, and opens release pull requests moved to the latest major versions. Releases now run on current, supported infrastructure, which means fewer delays between a fix shipping and it reaching you. See the [Quickstart](/quickstart) to get started.
- **Build tooling refresh.** A dozen development-only dependencies moved to newer releases. You get more reliable production builds. Nothing about how the app looks or works changes.

## Week of August 15, 2026

### Updates

- **Under-the-hood library upgrades.** Core libraries powering forms, dialogs, menus, tables, charts, and background data fetching moved to their latest patch and minor releases. You get faster interactions, smaller page downloads, and better compatibility with the latest React versions. Nothing about how the app looks or works day-to-day changes. See the [Quickstart](/quickstart) to get started.
- **Build tooling refresh.** The internal build and formatting toolchain moved to newer releases across styling, bundling, and code formatting. You get faster development builds and more reliable production output. Nothing about how the app looks or works day-to-day changes.

## Week of August 8, 2026

### Updates

- **Broader automated QA coverage.** A new automated QA suite now exercises the flows you use most. Covered flows include sign up and log in, connecting and disconnecting accounts, the dashboard, calendar navigation, AI caption generation, saving drafts, scheduling posts, publishing, filtering, and deletion. End-to-end journeys also run before every release, including dashboard CTA to scheduled post, AI caption to scheduled post, and publish now to analytics. You get earlier regression detection on the paths that matter, with no change to how the app works day-to-day. See the [Quickstart](/quickstart) to get started.

## Week of August 1, 2026

### Updates

- **More reliable releases.** A new end-to-end testing setup now seeds and tears down realistic data across the app before every release. You get faster iteration on the features you rely on — signups, subscriptions, blog, newsletter, contact forms, and checkout — with fewer regressions.
- **Stronger security posture.** Automated code security scanning now runs on every change and on a regular schedule, so vulnerabilities are caught earlier. No action is required from you — the checks run behind the scenes to help keep your account and data safer.
