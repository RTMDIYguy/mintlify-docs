## Welcome

There are two ways to build API documentation: [OpenAPI](https://mintlify.com/docs/api-playground/openapi/setup) and [MDX components](https://mintlify.com/docs/api-playground/mdx/configuration). This starter kit uses the following OpenAPI specification.

>
  View the OpenAPI specification file
</Card>

## Authentication

All API endpoints use bearer token authentication, which Mintlify picks up from the specification file.

```json
"security": [
  {
    "bearerAuth": []
  }
]
```
